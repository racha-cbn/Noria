# Noria

Web tool for explained credit scoring for profiles with little or no banking history (bachelor's web + AI project, Kaggle dataset *Home Credit Default Risk*).

**Project reference brief: [docs/project-brief.md](docs/project-brief.md)** (data, models, ethics and split choices, plus the decision log in section 12).

**Experiment log: [docs/experiments.md](docs/experiments.md)** (pre-registered measurements, decision rules fixed in advance, then results).

**Model card: [docs/model-card.md](docs/model-card.md)** · **Final results: [reports/final/final_results.md](reports/final/final_results.md)** (test set, used once).

**Convention:** All code, comments and documentation are written in English.

## Structure

```
noria/
├── docs/
│   ├── project-brief.md  # Reference project brief + decision log
│   ├── experiments.md    # Pre-registered experiment log
│   └── model-card.md     # Model card of the two application models
├── data/
│   ├── raw/              # Raw data (never modified, not versioned)
│   └── processed/        # Prepared data (not versioned)
├── notebooks/            # Exploration and experiments (01_eda_application.ipynb…)
├── src/                  # Reusable Python code (preparation, training, evaluation)
├── models/               # Trained models (.joblib, not versioned)
├── artifacts/            # Exported application models for the API (versioned, see src/predict.py)
├── tests/                # Checks (e.g. tests/test_predict.py)
├── reports/
│   ├── figures/          # Charts generated by the notebooks
│   ├── metrics/          # Experiment metrics (JSON)
│   └── final/            # Frozen-model manifest and final test results (E16)
├── requirements.txt
└── README.md
```
